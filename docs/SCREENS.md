```
┌──────────────┬────────────────────────────────────────┐
│              │                                        │

│              │                                        │

```

- 미로그인 상태로 접근 시 로그인 화면으로 리다이렉트
- 세션은 있으나 사용자 식별자가 없는 경우(계정 삭제 등)도 로그인 화면으로 보낸다
- **탭 바는 가로 스크롤이 아니라 줄바꿈(wrap) 처리**한다. 탭이 늘어나도 잘려서 안 보이면 안 됨

## S-02 대시보드

### 탭 구성

| 탭 | 노출 |
|---|---|
| 내 근태 현황 | 전체 |
| 달력 | 전체 |
| 전체 직원 근태 현황 | 관리자 |
| 시간대별 근무 현황 | 관리자 |

### S-02-1 내 근태 현황

**잔여 현황 카드** (그리드, 자동 줄바꿈)

```
┌───────────────────┐ ┌───────────────────┐ ┌───────────────────┐
│ 올해 잔여 연차       │ │ 잔여 병가          │ │ 이번 달 시간외근무   │
│                   │ │                   │ │                   │
│  15.0 일           │ │  6.0 일           │ │  17.0 시간         │
│                   │ │                   │ │                   │
│ 총 18일 중 3일 사용  │ │ 총 6일 중 0일 사용  │ │ 총 15시간 중 17.0시간│
│                   │ │                   │ │ 이번 달 한도 2.0시간 │
│                   │ │                   │ │ 초과  ← 적색        │
└───────────────────┘ └───────────────────┘ └───────────────────┘
```

- 연차 카드는 항상 표시. 그 외 휴가 종류는 **부여된 것만** 카드로 표시
- 시간외근무 카드: 부여 있으면 `총 N시간 중 M시간 사용` + `잔여 N시간`(녹색) 또는 `이번 달 한도 N시간 초과`(적색). 부여 없으면 `당월 승인 기준 누적 (부여시간 미설정)`
- **시간외근무만 월 단위**, 휴가는 연 단위

**최근 휴가 신청 내역** (5건) — 구분 / 기간 및 사용일수 / 사유 / 상태
**최근 근무시간 조정 신청 내역** (5건) — 적용 희망일 / 조정된 근무시간 / 사유 / 상태

상태 뱃지: `대기 중`(주황) `승인됨`(녹색) `반려됨`(적색)

### S-02-2 달력

```
[◀ 이전달]  2026년 8월  [다음달 ▶] [오늘]        [내 일정|전체 직원] ← 관리자만

■ 휴가  ■ 출장  ■ 교육  ■ 시간조정  ■ 시간외근무 · 기본 근무시간: 09:00-18:00

┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ 일   │ 월   │ 화   │ 수   │ 목   │ 금   │ 토   │   ← 일=적색, 토=청색
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│     │     │     │     │     │     │  1  │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  2  │  3  │  4  │  5  │  6  │  7  │  8  │
│     │     │     │     │3.5시간│     │     │   ← 종류별 색상 칩
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│  9  │ 10  │ 11  │ 12  │ 13  │ 14  │ 15  │
│     │     │     │연차  │연차  │     │     │   ← 기간 일정은 모든 날에
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│ 16  │ 17  │ 18  │(19) │ 20  │ 21  │ 22  │   ← (19)=오늘, 원형 강조
└─────┴─────┴─────┴─────┴─────┴─────┴─────┘
```

**칸 표시 규칙**
- 최대 3건까지 칩으로 표시, 초과 시 `+N건 더`
- 대기 중인 건은 `(대기)` 접미사 + 반투명
- 전체 직원 모드에서는 칩에 `직원명 · 내용` 형식
- 칩 hover 시 상세 내용 툴팁

**날짜 클릭 → 상세 패널**

```
2026-08-19 상세 근태
┌────────────────────────────────────────┐
│ 근태상황 · 정상 근무 09:00-18:00          │  ← 자동 판정
└────────────────────────────────────────┘

시간조정
┌────────────────────────────────────────┐
│ 홍길동 (개발팀) · 근무시간 09:00 - 18:00   │
│ → 09:30 - 18:30 · 사유: 육아 등원 [대기]  │
└────────────────────────────────────────┘
```

근태상황 판정 우선순위: 휴가 > 출장 > 교육 > 시간조정 > 정상 근무 (승인 건만 반영)

**월 전체 내역** (달력 하단)

```
2026년 8월 전체 내역 (4건)
┌──────────────┬──────────────┬──────────────┐
│ 휴가      1건 │ 출장      1건 │ 교육      1건 │
│ 08-12~08-13  │ 08-25        │ 08-27~08-28  │
│ 연차 2일[대기]│ 부산지사[대기] │ React심화[대기]│
└──────────────┴──────────────┴──────────────┘
```
항목 클릭 시 해당 날짜가 선택된다.

### S-02-3 전체 직원 근태 현황 (관리자)

직원명(부서) / 이번 달 시간외근무 합계 / 잔여 연차 / 기타 휴가 현황

### S-02-4 시간대별 근무 현황 (관리자)

승인된 근무시간 조정을 **시간대별로 그룹핑**해 표시. 각 시간대 아래에 해당 직원 카드(이름·부서·적용일).

## S-03 신청하기

### 탭 구성 (7개)

`휴가 신청` `시간외근무` `근무시간 조정` `교육 신청` `교육 결과` `출장 신청` `출장 결과`

### S-03-1 휴가 신청

| 항목 | 컨트롤 | 필수 |
|---|---|---|
| 휴가 구분 선택 | 드롭다운 (연차/오전반차/오후반차/병가/공가/가족돌봄휴가/대체휴가) | ✔ |
| 시작일 / 종료일 | 날짜 | ✔ |
| 사용 일수 (일) | 숫자, step 0.5, 기본 1 | ✔ |
| 신청 사유 | 여러 줄 | |

### S-03-2 시간외근무 신청

| 항목 | 컨트롤 | 필수 |
|---|---|---|
| 근무일 | 날짜 | ✔ |
| **월 한도 안내 배너** | 자동 표시 | — |
| 시작 시간 / 종료 시간 | 시각 | ✔ |
| 신청 시간 | 자동 계산 표시 | — |
| 상세 업무 내용 및 사유 | 여러 줄 | ✔ |

**한도 안내 배너** — 근무일 선택 시 그 달 기준으로 조회해 표시

```
┌──────────────────────────────────────────────┐
│ 2026년 8월 시간외근무 현황                       │  ← 청색 배경
│ 총 15시간 중 14.0시간 사용 · 잔여 1.0시간         │
│ ─────────────────────────────────────────    │
│ 이번 신청 2시간 반영 시 1.0시간 초과   ← 적색      │
└──────────────────────────────────────────────┘
```

| 상태 | 배너 |
|---|---|
| 여유 | 청색 배경, 잔여 녹색 |
| 초과 예정 | 청색 배경 + 하단 적색 경고 |
| 이미 초과 | **적색 배경**, `N시간 초과` |
| 부여 미설정 | 회색 배경, "부여시간이 아직 설정되지 않았습니다 (관리자 문의)" |
| 대기분 존재 | "결재 대기 중 N시간은 사용시간에 포함되지 않았습니다" 추가 |

제출 시 잔여 초과면 확인 창 → 취소 시 미신청, 확인 시 신청 진행

### S-03-3 근무시간 조정 신청

| 항목 | 컨트롤 | 필수 |
|---|---|---|
| 적용 희망일자 | 날짜 | ✔ |
| 현재 설정된 기본 근무시간 | 텍스트, 기본 `09:00 - 18:00` | ✔ |
| 변경 희망 근무시간 선택 | 드롭다운(프리셋 4종 + `직접 시간 입력`) | ✔ |
| 직접 입력 시간 | 텍스트 — **`직접 시간 입력` 선택 시에만 노출** | 조건부 ✔ |
| 조정 사유 | 여러 줄 | |

### S-03-4 / S-03-6 교육 · 출장 신청

| 교육 | 출장 |
|---|---|
| 교육명 ✔ | 출장지 ✔ |
| 교육기관 | 동행자 |
| 교육 시작일/종료일 ✔ | 출장 시작일/종료일 ✔ |
| 교육비(원) | 출장비(원) |
| 교육 목적 및 신청 사유 | 출장 목적 |

### S-03-5 / S-03-7 교육 · 출장 결과

```
교육 결과 보고
승인된 건에 대해서만 결과를 제출할 수 있습니다. 이미 제출한 결과도 다시 수정할 수 있습니다.

┌──────────────────────────────────────────────┐
│ 개인정보보호 실무자 과정          [제출 완료]     │
│ 한국생산성본부 · 2026-08-24 ~ 2026-08-26       │
│ ┌──────────────────────────────────────────┐ │
│ │ (결과 내용 입력 - 여러 줄)                  │ │
│ └──────────────────────────────────────────┘ │
│ 최종 제출: 2026. 8. 19. 오전 9:41   [결과 수정] │
└──────────────────────────────────────────────┘
```

- **승인된 건만** 목록에 표시. 없으면 "결과를 제출할 승인된 교육 신청 건이 없습니다."
- 뱃지: `결과 미제출`(주황) / `제출 완료`(녹색)
- 버튼: 미제출 시 `결과 제출`, 제출 후 `결과 수정`

## S-04 관리자 센터

### 탭 구성 (6개)

`신청 결재함` `교육/출장 결과 보고` `직원 계정 관리` `연도별 휴가 부여` `시간외근무 부여` `휴가 종류 설정`

### S-04-1 신청 결재함

5개 표를 세로로 나열. 각 표는 `PENDING` 건만 표시하며 행마다 `[승인] [반려]` 버튼.

| 표 | 컬럼 |
|---|---|
| 휴가 결재 대기 건 | 직원명(부서) / 구분 및 기간 / 사유 / 관리 |
| 시간외근무 결재 대기 건 | 직원명(부서) / 근무 일시 / 내용 / 관리 |
| 근무시간 조정 결재 대기 건 | 직원명(부서) / 적용 희망일 / 조정 시간 / 사유 / 관리 |
| 교육 신청 결재 대기 건 | 직원명(부서) / 교육명(기관) / 교육 기간 / 교육비 / 목적 / 관리 |
| 출장 신청 결재 대기 건 | 직원명(부서) / 출장지 / 출장 기간 / 동행자·출장비 / 목적 / 관리 |

처리 후 목록을 갱신한다.

### S-04-2 교육/출장 결과 보고

제출된 결과를 최신순 최대 50건씩 두 섹션(교육/출장)으로 열람. 각 건에 교육명·신청자·기간·제출일시·결과 전문(줄바꿈 유지).

### S-04-3 직원 계정 관리

이름 / 이메일 / 부서 / 권한(USER·ADMIN) 입력 후 등록. 이메일 중복 시 오류.

### S-04-4 연도별 휴가 부여 ★

```
┌─ 휴가 일괄 부여 ─────────────────────────────────┐
│ 적용 연도와 휴가 종류를 선택한 뒤, 아래 표에서 직원별  │
│ 부여 일수를 입력하고 한 번에 등록하세요.             │
│ 비워 둔 직원은 저장되지 않습니다.                    │
│                                                 │
│  적용 연도        휴가 종류                        │
│  [2026년 ▾]     [연차 ▾]                        │
└─────────────────────────────────────────────────┘

┌─ 2026년 · 연차 부여 일수 입력 ──── [입력한 내용 일괄 등록] ─┐
│ 직원 이름          │ 부여 일수  │ 사용 / 잔여              │
│ 관리자(김인사)(인사팀)│ [ 18 ] 일 │ 사용 3일 · 잔여 15일      │
│ 홍길동(개발자)(개발팀)│ [ 17 ] 일 │ 사용 2일 · 잔여 15일      │
└──────────────────────────────────────────────────────┘
```

- 전 직원 자동 로드, **기존 부여값 미리 채움**
- 휴가 종류 변경 시 표가 즉시 재조회됨
- 잔여는 **입력 중인 값 기준으로 실시간 계산**, 음수면 적색
- 빈 칸은 저장 대상에서 제외

### S-04-5 시간외근무 부여 ★

동일 패턴. **적용 연도만** 선택하고 휴가 종류 선택은 없다.

```
┌─ 시간외근무 일괄 부여 ────────────────────────────┐
│ 적용 연도를 선택한 뒤, 아래 표에서 직원별 월 부여시간을│
│ 입력하고 한 번에 등록하세요. 여기서 입력한 시간은     │
│ 해당 연도의 매월 사용할 수 있는 한도로 적용됩니다.     │
│  적용 연도  [2026년 ▾]                            │
└──────────────────────────────────────────────────┘

┌─ 2026년 시간외근무 월 부여시간 입력 ─ [입력한 내용 일괄 등록] ─┐
│ 직원 이름          │ 월 부여시간    │ 이번 달 사용 / 잔여      │
│ 관리자(김인사)(인사팀)│ [ 15 ] 시간/월│ 사용 14.0시간 · 잔여 1.0 │
│ 홍길동(개발자)(개발팀)│ [ 15 ] 시간/월│ 사용 0.0시간 · 잔여 15.0 │
└─────────────────────────────────────────────────────────┘
```

### S-04-6 휴가 종류 설정

코드 / 명칭 / 설명 / 유급 여부 입력 후 등록. 코드는 자동으로 대문자·언더스코어 변환되며 기존 코드면 수정된다.
