# PRD — 근태관리 기능

## 1. 배경 및 목적

사내 근태 업무(휴가·시간외근무·근무시간 조정·교육·출장)가 문서/수기로 관리되고 있어, 신청·결재 이력과 잔여 한도를 한곳에서 확인하기 어렵다. 통합관리시스템에 근태관리 모듈을 추가해 다음을 달성한다.

- 직원이 **본인의 잔여 연차·잔여 시간외근무를 신청 시점에 즉시 확인**할 수 있다.
- 관리자가 **직원별 한도를 일괄 부여**하고, 신청 건을 한 화면에서 결재한다.
- 부서/개인의 근태 일정을 **달력에서 종류 구분 없이 한눈에** 본다.

## 2. 사용자 및 권한

| 역할 | 설명 | 주요 권한 |
|---|---|---|
| `USER` (일반 직원) | 모든 임직원 | 본인 신청/조회, 본인 결과보고 제출 |
| `ADMIN` (관리자) | 인사 담당자 | 전 직원 결재·조회, 한도 부여, 기준정보 관리 |

권한 매트릭스는 [BUSINESS-RULES.md](BUSINESS-RULES.md#권한-매트릭스) 참고.

> 통합 시에는 통합관리시스템의 조직/권한 체계에 맞춰야 한다. 2단계(USER/ADMIN)는 프로토타입 기준이며, 실제로는 **부서장 1차 결재 → 인사팀 2차 결재** 같은 다단계 요구가 있을 수 있으므로 착수 전 확정 필요 ([INTEGRATION-NOTES.md](INTEGRATION-NOTES.md) 참고).

### 3.2 제외 (Out of scope) — 프로토타입 미구현

아래는 프로토타입에 **없으며**, 통합 시 필요 여부를 발주처가 결정해야 한다.

- 출퇴근 기록(태깅/IP/GPS), 실근로시간 집계
- 다단계 결재선, 대결/전결, 결재 의견
- 파일 첨부(교육 수료증, 출장 영수증 등)
- 알림(메일/SMS/사내 메신저), 결재 요청 푸시
- 연차 자동 산정(입사일 기준 발생·이월·소멸)
- 통계/리포트, 엑셀 다운로드
- 신청 취소·수정(현재는 등록 후 수정 불가)
- 결재 이력 감사로그(누가 언제 승인했는지)

## 4. 기능 상세

### F-01 휴가 신청

**입력**: 휴가 구분(드롭다운), 시작일, 종료일, 사용 일수(0.5 단위), 신청 사유(선택)

**휴가 구분 값**

| 코드 | 명칭 | 비고 |
|---|---|---|
| `ANNUAL` | 연차 | |
| `HALF_AM` | 오전 반차 | 차감은 `ANNUAL`에서 |
| `HALF_PM` | 오후 반차 | 차감은 `ANNUAL`에서 |
| `SICK` | 병가 | |
| `OFFICIAL` | 공가 | |
| `FAMILY_CARE` | 가족돌봄휴가 | |
| `COMPENSATORY` | 대체휴가 | |

`ANNUAL`~`COMPENSATORY`는 기준정보(휴가 종류)로 관리되어 **추가·변경 가능**하다. `HALF_AM`/`HALF_PM`은 신청 화면 전용 값이다.

**처리**: 등록 시 `대기` 상태. 관리자 승인 시 해당 연도·종류의 부여 일수에서 사용일수 차감.

---

### F-02 시간외근무 신청

**입력**: 근무일, 시작 시각, 종료 시각, 상세 업무 내용(필수)

**시간 자동 계산**: `(종료시각 - 시작시각)`, 음수면 +24시간(자정 넘긴 야간근무), 소수점 2자리.

**월 한도 안내** (핵심 요구사항)

근무일을 선택하면 **그 날짜가 속한 달**의 현황을 즉시 표시한다.

```
2026년 8월 시간외근무 현황
총 15시간 중 14.0시간 사용 · 잔여 1.0시간
```

시작/종료 시각을 입력하면 실시간으로 한 줄 추가:

```
이번 신청 2시간 반영 시 1.0시간 초과      (초과 시 적색)
이번 신청 1시간 반영 시 잔여 0.0시간      (여유 시 녹색)
```

제출 시 잔여를 초과하면 확인 창을 띄운다.

```
8월 시간외근무 잔여는 1.0시간입니다.
월 부여 15시간 / 사용 14시간

이번 신청 2시간을 더하면 16.0시간이 되어 1.0시간 초과합니다.
계속 진행할까요?
```

이미 초과한 달이면 "이미 초과했습니다" 문구로 안내한다.

> **정책 결정 필요**: 프로토타입은 **경고 후 진행 허용**(차단하지 않음)이다. 결재 단계에서 걸러낼 수 있고 불가피한 초과근무를 원천 차단하면 곤란할 수 있다는 판단. 발주처가 **하드 차단**을 원하면 명시할 것.

> **정책 결정 필요**: 사용시간은 **승인(APPROVED) 건만** 집계한다. 대기 중인 시간은 별도 문구로만 안내한다("결재 대기 중 N시간은 사용시간에 포함되지 않았습니다"). 대기분까지 선차감할지 결정 필요.

---

### F-03 근무시간 조정 신청

**입력**: 적용 희망일자, 현재 기본 근무시간, 변경 희망 근무시간, 조정 사유(선택)

**변경 희망 근무시간**은 프리셋 드롭다운 + 직접입력을 지원한다.
프리셋: `08:30 - 17:30`, `09:00 - 18:00`, `09:00 - 18:30`, `09:30 - 18:30`, `직접 시간 입력`

> 승인되어도 사용자의 기본 근무시간(`baseSchedule`)은 **자동 변경되지 않는다**. 승인 이력만 남는다. 통합 시 "해당일만 적용" 또는 "이후 기본값 변경" 중 무엇인지 확정 필요.

| 교육기관 | 동행자 |

### F-05 / F-07 교육·출장 결과보고

- **승인된 건에 한해** 신청자 본인이 결과 내용을 작성한다.
- 목록에는 본인의 승인 건만 노출되며, 각 건마다 제출 여부 배지(`결과 미제출` / `제출 완료`)와 최종 제출 일시를 표시한다.
- **이미 제출한 결과도 다시 수정 가능**하다(제출 시각 갱신).
- 관리자는 별도 탭에서 제출된 결과보고를 최근 50건까지 열람한다.

---

### F-10 대시보드

**내 근태 현황 탭**

- 잔여 연차 카드: `총 N일 중 M일 사용`
- 부여된 기타 휴가 종류별 카드(병가·공가 등): `총 N일 중 M일 사용`
- 이번 달 시간외근무 카드: `총 N시간 중 M시간 사용` + `잔여 N시간` 또는 `이번 달 한도 N시간 초과`
- 최근 휴가 신청 내역 5건, 최근 근무시간 조정 내역 5건

> 시간외근무 카드는 **월 단위**다(휴가 카드는 연 단위). 부여시간이 설정되지 않은 직원은 "당월 승인 기준 누적 (부여시간 미설정)"으로 표시.

**관리자 전용 탭**
- 전체 직원 근태 현황: 직원별 이번 달 시간외근무 합계, 잔여 연차, 기타 휴가 현황
- 시간대별 근무 현황: 승인된 근무시간 조정을 시간대별로 그룹핑하여 표시

---

### F-11 근태 달력

- 월 그리드에 **휴가·출장·교육·시간조정·시간외근무**를 종류별 색상으로 표시
- 여러 날에 걸친 일정(휴가/교육/출장)은 **해당 기간의 모든 날짜 칸에 표시**
- 한 칸에 3건까지 표시하고 초과분은 `+N건 더`
- **날짜 클릭 시** 해당일 상세 패널:
  - **근태상황** 자동 판정: 승인된 휴가 > 출장 > 교육 > 시간조정 순으로 우선, 아무것도 없으면 `정상 근무 09:00-18:00`
  - 종류별 상세 내역(신청자·기간·사유·상태)
- 하단에 **해당 월 전체 내역**을 종류별로 집계(각 종류별 건수 + 목록)
- 이전달/다음달/오늘 이동
- **관리자**는 `내 일정 ↔ 전체 직원` 전환 가능 (일반 직원은 본인 일정만)
- **반려된 건은 달력에 표시하지 않는다** (실제로 발생하지 않은 일정이므로)

---

### F-12 / F-13 일괄 부여 (관리자)

두 화면 모두 동일한 패턴이다.

```
[상단]  적용 연도 선택   (휴가는 + 휴가 종류 선택)
[하단]  ┌─────────────┬────────────┬──────────────┐
        │ 직원 이름    │ 부여 일수/시간 │ 사용 / 잔여    │
        ├─────────────┼────────────┼──────────────┤
        │ 홍길동(개발팀)│ [   15   ] │ 사용 2일·잔여 13일│
        │ 김인사(인사팀)│ [   18   ] │ 사용 3일·잔여 15일│
        └─────────────┴────────────┴──────────────┘
                          [ 입력한 내용 일괄 등록 ]
```

- 전 직원 명단이 자동으로 로드되고, **기존 부여값이 입력칸에 미리 채워진다**.
- **비워 둔 직원은 저장하지 않는다** (일부만 수정할 때 안전).
- 휴가는 종류를 바꾸면 표가 그 종류 기준으로 즉시 갱신된다.
- 시간외근무 부여시간은 **월 한도**이며, 선택한 연도의 매월에 동일하게 적용된다. (월별로 다른 값을 주는 기능은 없음 — 필요 시 요건 추가)
- 연차(`ANNUAL`) 부여 시 사용자 마스터의 연차 총량도 함께 동기화된다.

## 5. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 권한 | 모든 관리자 API는 서버에서 역할을 재검증한다. 화면 숨김만으로 처리하지 않는다. |
| 데이터 격리 | 일반 직원은 타인의 신청·일정을 조회할 수 없다. 달력의 전체조회 파라미터도 서버에서 강등 처리한다. |
| 날짜 처리 | 날짜형 데이터는 UTC 자정 기준으로 저장하고 조회 경계도 UTC로 맞춘다. 월 경계 계산 시 타임존 오차 주의. |
| 동시성 | 일괄 부여는 트랜잭션으로 처리한다(일부만 저장되는 상태 방지). |
| 응답성 | 달력 월 이동 시 이전 요청의 응답이 뒤늦게 도착해 화면을 덮어쓰지 않아야 한다. |
| 접근성 | 표는 좁은 화면에서 가로 스크롤로 처리하고 본문이 가로로 밀리지 않아야 한다. |

## 6. 용어

| 용어 | 정의 |
|---|---|
| 부여(일수/시간) | 관리자가 직원에게 할당한 사용 가능 한도 |
| 사용 | 승인 완료된 신청의 합계 |
| 잔여 | 부여 − 사용 |
| 결재 | 관리자의 승인 또는 반려 |
| 결과보고 | 교육·출장 종료 후 신청자가 제출하는 수행 내용 |
