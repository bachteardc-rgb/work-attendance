# 인수 테스트 시나리오

검수 기준으로 사용한다. 각 항목은 **합격/불합격이 명확히 갈리도록** 작성했다.

## 사전 조건

- 관리자 계정 1개, 일반 직원 계정 2개 이상
- 휴가 종류 기준정보 등록 완료(연차·병가·공가·가족돌봄휴가·대체휴가)

## A. 한도 부여 (관리자)

| # | 시나리오 | 기대 결과 |
|---|---|---|
| A-1 | 휴가 부여 화면에서 연도 2026, 종류 `연차` 선택 | 전 직원 명단이 표로 표시되고, 기존 부여값이 입력칸에 채워져 있다 |
| A-2 | 두 직원에게 각각 18일, 17일 입력 후 일괄 등록 | 두 건 모두 저장되고, 재조회 시 값이 유지된다 |
| A-3 | 휴가 종류를 `병가`로 변경 | 표가 병가 기준 값으로 즉시 갱신된다 |
| A-4 | 한 직원만 값을 지우고 나머지는 그대로 둔 채 등록 | **빈 칸 직원은 변경되지 않고**, 입력한 직원만 저장된다 |
| A-5 | 부여 일수에 `-3` 입력 후 등록 | 오류 메시지, **아무것도 저장되지 않는다** |
| A-6 | 시간외근무 부여 화면에서 연도 2026 선택, 전원 15시간 입력 후 등록 | 저장되고 재조회 시 유지된다 |
| A-7 | 시간외근무 부여시간에 문자 입력 후 등록 | 오류 메시지, 저장되지 않는다 |

## B. 시간외근무 월 한도 안내 ★ 핵심

**전제**: 대상 직원의 2026년 월 부여시간 = **15시간**, 8월 승인 사용 = **14시간**

| # | 시나리오 | 기대 결과 |
|---|---|---|
| B-1 | 신청 화면에서 근무일 `2026-08-18` 선택 | `2026년 8월 시간외근무 현황 / 총 15시간 중 14.0시간 사용 · 잔여 1.0시간` 배너 표시 |
| B-2 | 시작 19:00, 종료 21:00 입력 | `신청 시간: 2시간` 표시 + `이번 신청 2시간 반영 시 1.0시간 초과` **적색** 표시 |
| B-3 | 그대로 제출 | 확인 창에 `잔여는 1.0시간`, `2시간을 더하면 16.0시간이 되어 1.0시간 초과` 안내 |
| B-4 | 확인 창에서 **취소** | 신청되지 않는다 |
| B-5 | 확인 창에서 **확인** | 신청된다 (경고형 정책 기준. 하드 차단 정책이면 이 항목은 "신청 거부"로 변경) |
| B-6 | 시작 19:00, 종료 20:00(1시간)으로 변경 | `잔여 0.0시간` **녹색** 표시, 제출 시 확인 창 **없음** |
| B-7 | 사용량을 17시간으로 만든 뒤 근무일 재선택 | 배너가 **적색 배경**으로 `총 15시간 중 17.0시간 사용 · 2.0시간 초과` |
| B-8 | 근무일을 `2026-09-01`로 변경 | 9월 기준으로 재조회되어 `사용 0.0시간 · 잔여 15.0시간` (**월 단위 리셋 확인**) |
| B-9 | 부여시간이 없는 직원으로 신청 | `부여시간이 아직 설정되지 않았습니다 (관리자 문의)` 안내, 경고 없이 신청 가능 |
| B-10 | 결재 대기 건이 있는 상태에서 조회 | `결재 대기 중 N시간은 사용시간에 포함되지 않았습니다` 문구 표시 |

**시간 계산 검증**

| # | 시작 | 종료 | 기대 |
|---|---|---|---|
| B-11 | 18:00 | 21:30 | 3.5시간 |
| B-12 | 18:00 | 08:00 | **14시간** (자정 넘김) |

## D. 결재 흐름

| # | 시나리오 | 기대 결과 |
|---|---|---|
| D-1 | 5종(휴가·시간외·조정·교육·출장) 각 1건 신청 | 관리자 결재함의 **해당 표에 각각 나타난다** |
| D-2 | 휴가 1건 승인 | 상태 `승인됨`, 해당 연도·종류의 **사용일수가 신청 일수만큼 증가** |
| D-3 | 연차 승인 후 대시보드 확인 | 잔여 연차가 즉시 감소해 있다 |
| D-4 | 오전 반차 0.5일 승인 | **연차**에서 0.5일 차감된다 (반차 별도 항목 아님) |
| D-5 | 이미 승인된 건을 다시 승인 시도 | **거부**된다 (`이미 처리된 신청입니다`) — 5종 모두 |
| D-6 | 반려 처리 | 상태 `반려됨`, **차감 발생하지 않음** |
| D-7 | 일반 직원이 결재 API 직접 호출 | **403** 거부 |

## E. 교육·출장 결과보고

| # | 시나리오 | 기대 결과 |
|---|---|---|
| E-1 | 대기 중인 교육 건에 대해 결과 탭 확인 | 목록에 **나타나지 않는다** (승인 건만) |
| E-2 | 교육 승인 후 결과 탭 확인 | 목록에 나타나고 `결과 미제출` 뱃지 |
| E-3 | 결과 내용 입력 후 제출 | `제출 완료` 뱃지로 변경, 최종 제출 일시 표시, 버튼이 `결과 수정`으로 바뀜 |
| E-4 | 공백만 입력 후 제출 | 거부 |
| E-5 | 내용 수정 후 재제출 | 저장되고 제출 일시가 갱신된다 |
| E-6 | 관리자가 결과보고 탭 확인 | 제출된 내용이 신청자·기간·제출일시와 함께 열람된다 |
| E-7 | 타인의 신청 건에 결과 제출 시도(API 직접 호출) | **403** 거부 |
| E-8 | 승인되지 않은 건에 결과 제출 시도 | **400** 거부 |

## F. 근태 달력 ★ 핵심

**전제**: 8/12~8/13 연차, 8/25 출장, 8/27~8/28 교육, 8/6 시간외근무(3.5h), 8/19 근무시간조정

| # | 시나리오 | 기대 결과 |
|---|---|---|
| F-1 | 2026년 8월 달력 조회 | 위 5건이 **종류별 색상**으로 해당 날짜에 표시된다 |
| F-2 | 8/12, 8/13 칸 확인 | **두 날짜 모두**에 연차가 표시된다 (기간 일정 펼침) |
| F-3 | 8/27, 8/28 칸 확인 | **두 날짜 모두**에 교육이 표시된다 |
| F-4 | 대기 중인 건 확인 | `(대기)` 표기 + 반투명 처리로 구분된다 |
| F-5 | 반려된 건 확인 | 달력에 **표시되지 않는다** |
| F-6 | 8/12 클릭 | 상세 패널에 `근태상황 · 휴가 (연차)` 와 휴가 상세가 표시된다 |
| F-7 | 일정 없는 날짜 클릭 | `근태상황 · 정상 근무 09:00-18:00` 표시 |
| F-8 | 하단 월 전체 내역 확인 | 종류별 건수와 목록이 정확히 집계된다 (총 5건) |
| F-9 | `다음달 ▶` 클릭 | 9월 데이터로 갱신된다 |
| F-10 | 월 이동 버튼을 **빠르게 여러 번** 클릭 | 최종 선택한 달의 데이터가 표시된다 (이전 응답이 덮어쓰지 않음) |
| F-11 | 한 날짜에 4건 이상 존재 | 3건 표시 + `+N건 더` 표기 |
| F-12 | 관리자가 `전체 직원` 전환 | 전 직원 일정이 `직원명 · 내용` 형식으로 표시된다 |
| F-13 | **일반 직원** 화면 | `내 일정/전체 직원` 전환 버튼이 **보이지 않는다** |
| F-14 | 일반 직원이 전체조회 파라미터로 API 직접 호출 | 본인 데이터만 반환된다 (**서버에서 강등**) |

## H. 화면 표시

| # | 시나리오 | 기대 결과 |
|---|---|---|
| H-1 | 모든 탭 바 확인 | 탭이 많아져도 **잘려서 안 보이는 탭이 없다** (줄바꿈 처리) |
| H-2 | 좁은 화면에서 부여 표 확인 | 직원 이름이 한 글자씩 쪼개지지 않고, **표만** 가로 스크롤된다 |
| H-3 | 금액 표시 | `350,000원` 형식 |
| H-4 | 저장/제출 중 | 버튼 비활성 + `저장 중...` 표시, 중복 제출 불가 |
| H-5 | 근무시간 조정에서 `직접 시간 입력` 선택 | 입력칸이 나타나고, **입력한 값이 그대로 신청된다** |
